Política de Privacidade e Tratamento de Dados – HugDown

O HugDown respeita sua privacidade e garante que todos os dados pessoais coletados sejam tratados conforme a Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018).

1. Controlador dos Dados

O HugDown é o responsável pelo tratamento dos dados coletados na plataforma.

2. Dados Coletados

Informações fornecidas pelo usuário: nome, e-mail, senha e dados de perfil.

Informações técnicas: IP, dispositivo, navegador e registros de acesso.

Conteúdos publicados na plataforma (postagens, comentários, imagens, vídeos).

3. Finalidades do Tratamento

Os dados são utilizados para:

Criar e manter a conta do usuário.

Permitir interações na plataforma.

Garantir a segurança do ambiente.

Cumprir obrigações legais.

Melhorar funcionalidades e serviços.

4. Compartilhamento e Acesso

Moderadores não têm acesso a dados pessoais privados.

Dados não são vendidos, alugados ou cedidos a terceiros.

O compartilhamento só ocorre em situações legais, como cumprimento de ordens judiciais.

5. Direitos do Usuário (LGPD)

Você pode:

Solicitar acesso, correção ou exclusão dos seus dados.

Solicitar anonimização ou bloqueio de informações.

Revogar o consentimento a qualquer momento.

Solicitar portabilidade de dados.

6. Segurança dos Dados

Senhas são criptografadas.

Medidas técnicas e administrativas protegem contra acessos não autorizados.

Nenhum sistema é 100% seguro, mas adotamos os melhores padrões de proteção.

7. Retenção

Os dados são mantidos pelo tempo necessário ao funcionamento da conta.

Após exclusão da conta, os dados podem ser anonimizados ou eliminados, salvo obrigação legal.

8. Alterações na Política

O HugDown pode atualizar esta Política de Privacidade. Alterações significativas serão comunicadas na plataforma.

9. Encarregado de Proteção de Dados (DPO)
